# Video Downloader

Local-first video downloader. Paste a supported public video URL, inspect it, choose a quality, and download it locally.

Only download content you have permission to download. This project does not bypass authentication, private-content restrictions, DRM, paywalls, or other access controls.

## Stack

- React + Vite frontend
- FastAPI backend
- yt-dlp media extraction
- FFmpeg for media merging/conversion
